# Digital World Patcher

Fan translations and data mods for **Digimon World DS**, **Digimon World Dawn** and **Digimon World Dusk** (Nintendo DS, USA).

**Patch in your browser:** https://kirides.github.io/digital-world-patcher/

Load your own ROM. The page recognises the game by its checksum, applies the German translation, and lets you edit
every digivolution route (presets such as "Offline: every Digimon without matching", or your own routes, shareable as
JSON). A lookup shows where every Digimon appears in the wild and how often: each section with a picture from the
ROM (DS: battle background, Dawn/Dusk: field map) and its full encounter list, with or without the mod's additions.
Everything runs locally; the ROM never leaves your device. No ROMs are part of this repository.

**Privacy:** the page loads nothing from third parties (no external fonts, scripts, CDNs, analytics or cookies);
all files come from this repository. Only your settings (mute, music, digivolve sound) are kept in your browser's
localStorage. Hosting is GitHub Pages, see GitHub's privacy statement for its server logs.

## Layout

```
web/            the patcher page (GitHub Pages): index.html, style.css, core.js, app.js
  data/         meta.json: supported ROMs, table addresses, presets (generated by tools/build_web.py)
  i18n/         page texts, one file per language (de.json, en.json)
  patches/      language patches (.bps), generated by tools/dgmtool.py release
translations/   one folder per text set: ds/ (Digimon World DS), dawn/ (Dawn and Dusk share their text)
  <set>/catalog.json   every string extracted from the ROM, with box sizes
  <set>/<lang>.json    {"English source": "translation"}; <lang>.overrides.json for single occurrences
mods/           one folder per data mod: <name>/mod.json (+ README.md)
tools/          Python toolkit: extract, translate, check, build, release, mods, web build
  langs/<lang>.json    language profile: letters, extra glyphs, style, glossary
tests/          node tests for the web core against the Python builds
```

## Page languages

The page itself is multilingual: `web/i18n/<code>.json` holds every text (German and English so far). The page
picks the browser language (fallback English), the switcher is left of the GitHub link, and the choice is remembered.
When a translation patch for that language exists for the loaded game, it is preselected.
A new page language is one new file: copy `web/i18n/en.json`, translate the values, set `_name`, then run
`tools/build_web.py` so it appears in the switcher.

## Add a language

1. Copy `tools/langs/de.json` to `tools/langs/<code>.json` and adapt name, letters, style and glossary.
2. Translate: `python tools/dgmtool.py translate translations/ds --lang <code>` (and `translations/dawn`).
   This writes `translations/<set>/<code>.json`, the file to review and commit. `batch.py` and `export`/`import`
   (CSV) support manual translation and native-speaker review.
3. Build the patches: `python tools/dgmtool.py release --lang <code> --workdir translations --out <dir> <ROMs>`.
4. Add the patches to the page: `web/patches/` and the language in `tools/build_web.py` (`translations=` per game; currently German only),
   plus `web/i18n/<code>.json` if the page should also speak it.

## Add a mod

1. Create `mods/<name>/mod.json` (see `mods/ds-offline/mod.json` and the format in `tools/mod.py`):
   `game`, `name`, and `evolutions` (route changes), `encounters` (DS: extra wild Digimon),
   `wild_copy` / `drop_self_gates` (Dawn/Dusk, see `mods/dawn-dusk-offline`).
   Species ids are the game's own; the editor on the web page shows every Digimon and route.
2. Try it: `python tools/mod.py mods/<name> <rom.nds> <out.nds>`, or as BPS: `--bps`.
3. `python tools/build_web.py --patches web/patches <ROMs>` adds it to the page as a preset of its game.
4. `node tests/test_web.js <rom dir> <release dir> <mod dir>` checks the page against the Python builds.

## Rebuild the page data

```
python tools/build_web.py --patches web/patches "Digimon World DS.nds" "Digimon World - Dawn.nds" "Digimon World - Dusk.nds"
python tools/build_web.py --patches web/patches --single patcher.html <same ROMs>   # one self-contained file
```

The ROMs are only read (checksums, table positions). Details on the toolkit: [tools/README.md](tools/README.md).
