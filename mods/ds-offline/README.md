# ds-offline: every Digimon without matching (Digimon World DS)

In Digimon World DS, trading only gives a stat bonus; what locks Digimon away is **Digimon Matching** (DigiEggs
from a second player). Without it, these are unobtainable: Omnimon, Imperialdramon Paladin Mode, Gallantmon Crimson
Mode, Numemon, Digitamamon and Imperialdramon (via Numemon), ChaosGallantmon, and the Chibomon / Veemon line.

| Change | Route / encounter |
|---|---|
| MetalGreymon → Omnimon | Lv 62 + 90 % friendship (was: Omnimon already befriended) |
| Antylamon → ChaosGallantmon | Lv 62 + 20,000 Dark EXP (was: ChaosGallantmon already befriended) |
| Paildramon → Imperialdramon Paladin Mode | Lv 70 + 40,000 Holy EXP |
| WarGrowlmon → Gallantmon Crimson Mode | Lv 70 + 40,000 Dragon EXP |
| Sukamon → Numemon → Digitamamon | Lv 15, Lv 30 |
| Chibomon | wild in Data Forest (2nd part), 8 % |
| Veemon | wild in Sheer Valley, 8 % |

Data only (dat/sk, dat/ec records rewritten in place); matching keeps working as in the original.
With the mod the web page's check counts 240 of 240 obtainable Digimon (Koemon, Bokomon, Neemon and Tortomon are
NPC entries that are not obtainable in the original game in any way).
